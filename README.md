# <img width='24' src="./src/main/resources/icon.png"> More Tool Variants
> ![Mod Icon](https://raw.githubusercontent.com/pnk2u/resources/main/ModProjects/More-Tool-Variants/pres/logo/logo_c.png)
>
> A simple mod adding wood variants for Minecraft's Tool Items (Pickaxe, Axe, Shovel, Hoe, Brush).

### Compatibility

- Minecraft: `1.20.1`, `1.21(.1)`, `1.21.4`~`1.21.10`
- Mod Loader: _Fabric_
- Requires: [`Fabric API`](https://modrinth.com/mod/fabric-api), [<img width='16' src="https://raw.githubusercontent.com/pnk2u/resources/main/ModProjects/More-Stick-Variants/pres/logo/logo_c.png"> `More Stick Variants (MStV)`](https://modrinth.com/mod/more-stick-variants)

### ᴬ⃯ ᵦ⃔ Translations
